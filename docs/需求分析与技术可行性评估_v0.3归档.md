# ContentFlow 需求分析与技术可行性评估

版本：v0.3。日期：2026-10-31（Asia/Shanghai）。第 006 轮用户明确修正产品目标；保留 [v0.2 归档](需求分析与技术可行性评估_v0.2归档.md) 和 [v0.1 归档](需求分析与技术可行性评估_v0.1归档.md)。

## 1. 已确认目标

**主题 → DeepSeek Flash 一次生成标题、中文旁白和有序英文画面关键词 → 人工编辑确认 → MoneyPrinterTurbo 在线素材搜索下载 → Edge 配音、字幕和剪辑 → 网页预览下载。**

第五轮本地 MP4 仅验证媒体链。用户在本轮反馈已完成人工观看验收；记录该后续反馈，不追溯改写第五轮当时的工具记录。本地 MP4 仅备用，不再是默认 P0，不在在线源失败时静默替代。

Pexels 默认，Pixabay 仅由用户主动选择；关闭背景音乐、付费生成、账号发布。单用户、本机、同时一个生成任务，目标 15–30 秒、9:16。实际时长随语音，不承诺精确时长或逐句语义对齐。

## 2. 有效约束

- 个人课程项目，报告截止 2026-11-02 23:59（北京时间），预留报告和交付检查。
- 现有 DeepSeek Key/余额，不充值或新增收费渠道；余额不足停止；显式 deepseek-flash，不回退 Pro。
- 一次按钮操作一次结构化请求，输出上限 1200 tokens、关闭思考；不自动重试计费请求。
- Python + Streamlit + SQLite；Coding Agent 分阶段开发、测试、记录，不要求用户手工编程。
- MPT 固定 1.3.6 / commit 436b0e9cc830ef7639e33388917e389cf30d3307；不修改上游源码。Edge 7.3.1 为第五轮批准的独立依赖覆盖，uv.lock 不变。
- 凭证仅本机私有配置/指定环境；不在聊天收集，不入任务表、日志、截图、公开代码或 Git；不假设 .env 自动加载。
- 不做注册/登录、多用户、自动发布、Redis、Celery、多 Agent 或通用工作流框架；不自动提交或推送。

## 3. 实际核验与可行性

固定 Schema、Controller、task.py、material.py 与实时 OpenAPI 确认 video_source、video_script、video_terms、match_materials_to_script、sequential 均可用。非空脚本和关键词跳过上游相应 LLM 请求；match=true 保持顺序并跳过可选关键词重排。

素材匹配为关键词分组轮询下载和顺序剪辑，不保证逐句时间对齐。此版本 Pexels 筛选精确 1080×1920 rendition 及最小时长，有第三方结果也可能被过滤为空；部分网络/API 异常也返回空列表，需要结合脱敏日志排查。

初始检查：上游 Pexels、Pixabay、DeepSeek 均未配置，相应环境变量也缺失。用户拥有密钥不等于本机已接入。应用可实现并运行，但两个主题真实在线闭环受凭证阻塞，不能用模拟结果或第五轮本地样片代替。

[Pexels 官方页面](https://www.pexels.com/api/)当前提示暂停新 Key 发放。已有 Key 可配置后实测；无现成 Key 时可由用户选择免费 [Pixabay API](https://pixabay.com/api/docs/)，不静默切换。

## 4. 架构与复用

Streamlit → ContentFlow 结构化 DeepSeek 请求/人工审核/固定 REST 工作流 → 本机 MPT 在线素材与媒体处理。SQLite 保存草稿、审核快照、ID、状态、错误及产物引用；runtime 保存数据库、视频和日志，均忽略。

按本轮结构化结果要求，ContentFlow 单次直接调用已有 DeepSeek 官方资源，返回 title/script/video_terms。完整传给 MPT，避免其再生成脚本或关键词。MPT 继续负责库存素材检索、异步任务、Edge、MoviePy/FFmpeg，不重复实现剪辑引擎。

## 5. 当前需求追踪

| 编号 | 等级 | 验收条件 |
| --- | --- | --- |
| FR-01 | P0 | 主题 1–120 字；缺模型 Key 不发请求 |
| FR-03 | P0 | 可编辑标题、中文旁白、4 个具体可见英文画面短语，按叙事排序 |
| FR-04 | P0 | 显式审核当前内容；主题、标题、脚本、词序或来源变化使审核失效 |
| FR-05 | 备用 | 本地上传保留上游能力，不作为本轮默认界面 |
| FR-06 | P0 | 默认 Pexels、主动选择 Pixabay；展示实际来源、搜索词和可用作者信息 |
| FR-07 | P0 | 实际 POST、保存 task_id；9:16、match=true、sequential、无配乐 |
| FR-08 | P0 | 有声且烧录中文字幕的 MP4；网页预览下载；显示实际时长/分辨率/大小 |
| FR-09 | P0 | 真实状态/进度和明确错误，不凭进度虚构阶段 |
| FR-10 | P0 | 持久化防重锁；刷新、重复点击不重发；结果不确定进入需核对 |
| FR-11 | P0 | 应用重启保留记录；后端查不到时需核对；仅 GET 下载可单独重试 |
| FR-12 | P0 | 明确 Flash 和本机地址，秘密隔离，不切换 Pro/新付费渠道 |
| FR-13 | P0 | 分阶段真实 AI/测试记录，媒体另作报告附件 |
| FR-14 | P0 | 缺 Key、无结果、网络失败明确阻塞，不退回本地或付费生成 |

## 6. 测试与退出条件

两个不同主题均实际通过模型生成、人工审核、在线搜索下载、真实任务、中文视听和网页预览下载；核对素材相关性及叙事顺序，记录请求、ID、状态、产物与截图。原自动化测试全部通过，并覆盖空输入、审核后编辑、防重/并发、提交不确定、网络、无结果、鉴权、重启与下载错误。

模拟测试、已有产物只读回归、真实在线生成必须分别标记。缺 Key 或截图/观看未完成时如实说明，不降低两主题真实验收条件。两主题通过前不宣称完整 MVP 端到端完成。

入口 app.py；详见 [运行说明](../README.md)、[API 说明](MoneyPrinterTurbo_API集成说明.md)、[AI 开发记录](AI辅助开发过程记录.md) 第 006 轮。进度与未决项以实际证据为准。
