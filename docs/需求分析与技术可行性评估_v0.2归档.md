## 1. 结论

在不新增充值、复用现有 DeepSeek 余额的前提下，采用“本地视频素材 + 原生 DeepSeek Provider + Edge TTS + Edge 时间戳字幕 + 本地 FFmpeg 合成”具备技术依据。**结论为有条件可行，尚未通过运行验证。** 最大不确定项是本机依赖安装、Edge TTS 联网可用性和实际 API 素材路径映射。

截止日期为 2026-11-02 23:59（北京时间），按日期计算只剩约两天及 10 月 31 日剩余时间，不能再采用原稿 13–19 个工作日的计划。唯一最高优先级是：ContentFlow 真实调用本地 MoneyPrinterTurbo REST API，并获得可播放的有声字幕视频。选题候选、自然语言脚本改写等功能后置。

本项目的“AI Agent”采用固定工作流：生成脚本、人工确认、工具调用、状态反馈和结果交付。没有必要引入多 Agent、通用 DAG 或自由规划框架。

## 4. 经收紧的 MVP

### P0：截止前必须完成

1. 一个 Streamlit 应用，允许用户直接输入主题；不要求先生成三个选题。
2. 调用本地 MoneyPrinterTurbo 的脚本 API，由其原生 DeepSeek Provider 生成中文口播稿；用户查看、编辑并确认。
3. 上传或选取 1–3 个本地 MP4，展示文件信息及来源说明；使用一个固定字幕、配音和画幅模板。
4. 将已确认脚本和已确认素材提交给 MoneyPrinterTurbo 视频 API，获取上游任务标识，轮询真实状态。
5. 展示明确的处理中、成功、失败、需核对状态，支持成片预览和下载。
6. SQLite 最小持久化：主题、确认脚本、素材引用、上游任务标识、状态、错误摘要、时间及产物位置。
7. 防止页面刷新或重复点击重复提交；生成失败不自动盲目重发，只允许显式新尝试。
8. 保存分阶段 AI 交互摘要、真实样片、验收记录、复用边界及课程报告。

默认短片目标为 15–30 秒，一次一个视频、同时一个任务。时长由脚本和语音决定，记录实际值，不承诺精确秒数。当前上游 schema 的 9:16 对应 1080×1920，优先使用这一原生规格；撤销原稿未经验证的 720×1280 要求。若机器合成压力大，先缩短视频和减少素材，不优先增加转码功能。[视频参数定义](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/app/models/schema.py)

脚本文案的人工编辑属于内容审核，不是手工编写程序代码。应用不提供代码编辑入口。

### P1：仅在真实闭环及报告草稿完成后安排

选题候选、素材关键词独立生成、自然语言改写脚本、复杂历史版本对比、第二种视频模板、在线素材检索和任务报告导出。

### 本次不做

多用户、登录权限系统、云部署、拖拽工作流、多 Agent、自主上网、热点爬虫、文生视频、数字人、自动发布、自动配乐、批量生成、任意断点续跑、独立前端框架。

背景音乐关闭，在线素材源关闭，不配置生成式视频或图像服务。保留源码中的可选功能不等于启用它们，也不应承诺自动卸掉其所有安装依赖。

## 5. 用户场景与验收要求

正常流程：输入主题 → 经上游脚本接口调用 DeepSeek → 确认口播稿 → 确认本地素材 → 提交视频任务 → 查询状态 → 预览及下载。

| 编号 | 优先级 | 需求与可检查条件 |
| --- | --- | --- |
| FR-01 | P0 | 主题非空；未配置服务时提示原因，不创建生成任务 |
| FR-02 | P1 | 三个选题候选；本版不作为完成前提 |
| FR-03 | P0 / P1 | P0 为生成、编辑、确认脚本并保存提交快照；自然语言改写和完整版本对比降为 P1 |
| FR-04 | P0 | 没有确认脚本和至少一个有效素材时，不允许提交视频；修改内容后必须重新确认 |
| FR-05 | P0 | 仅接受 MP4，单文件 <=100 MB，每任务最多 3 个；校验实际视频流，不能仅检查扩展名 |
| FR-06 | P0 | 显示素材来源说明和元数据；用户确认固定模板使用的素材；允许上游按模板重复片段，记录此行为，不宣称逐句语义匹配 |
| FR-07 | P0 | 真实 POST 到 MoneyPrinterTurbo；保存 task_id；使用审核过的 video_script 和 local 素材 |
| FR-08 | P0 | 获取可播放 MP4，有中文配音和烧录字幕；预览及下载成功，记录实际画幅、时长 |
| FR-09 | P0 | 轮询真实状态，保留错误摘要；没有阶段细节时只显示整体生成中 |
| FR-10 | P0 | 无自动重提视频；提交超时且无法确定是否被接收时进入“需核对”，不伪称失败或成功；用户核对后再决定新尝试 |
| FR-11 | P0 | 重启后历史和上游标识可查；对于未完成任务先查询上游，查不到时进入需核对；不要求后台自动恢复执行 |
| FR-12 | P0 | DeepSeek 模型和视频后端地址明确；完整密钥不进入 SQLite、页面、日志或提交历史 |
| FR-13 | P0 | 生成中禁止重复点击提交；Streamlit rerun 不会重新发起同一次生成 |
| FR-14 | P1 | 在线素材检索，本版不依赖该能力 |
| FR-15 | P0 | 仅允许已确定的服务组合；切换到新付费服务前停止并说明费用及替代方案 |

任务状态：草稿 → 脚本就绪 → 输入已确认 → 提交中 → 生成中 → 成功 / 失败 / 需核对。等待确认和失败期间保留输入。新尝试保留旧结果，不覆盖成功产物。一次提交前持久记录本地尝试编号；上游标识回写失败也要标记不确定，不能自动再提交。

非功能要求：中文提示清晰；默认本机访问；查询间隔约 3–5 秒；15 分钟未完成时告警并核对上游，而不是宣称任务已取消。错误日志脱敏，路径限制在受管素材和产物目录。视频需完整观看一次，确认声音可辨、中文字体正常且字幕未明显裁切。不设未经测量的生成时限保证。

## 6. MoneyPrinterTurbo 部署要求核验

资料检查对象是官方仓库当前 main，查询日期 2026-10-31；尚未锁定 release/commit，因此以下是接口评估依据，实施前需固定版本并核对本地 /docs。版本清单中显示 mpt 1.3.9，不等于已验证对应发布包。

### 6.1 依赖及部署方式

上游 pyproject 声明 Python >=3.11，包含 MoviePy、FastAPI、Streamlit、edge-tts、imageio-ffmpeg、faster-whisper 等。即使只用 Edge 字幕，安装清单仍可能带入 Whisper 相关包；运行不下载模型与安装不包含依赖是两件事。[上游依赖清单](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/pyproject.toml)

建议本机源码部署、独立虚拟环境、锁定上游版本，优先按其 uv 锁文件安装；不以 Docker 为首选，减少路径映射和镜像下载变量。Python 3.11 是备选兼容环境；先判断现有 3.13 的锁文件安装结果，不修改全局 Python。

发现当前 pyproject 的 uv override 对 Pillow 有特殊设置，不能假设直接 pip 安装与 uv 锁定环境等价；若出现解析冲突，先核对选定 release 的说明和锁文件，记录实际错误，不临时无界升级所有依赖。此项构成部署验证门槛。[依赖与 override 配置](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/pyproject.toml)

API 入口 main.py 通过 Uvicorn 加载 app.asgi:app，监听值来自配置。后续配置为 127.0.0.1，拟用 8080 端口，启动后通过 /docs 检查接口。源码入口和安装包命令不能混用推断。[API 启动入口](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/main.py)

FFmpeg 为本地音视频处理所需；上游说明支持自动探测或配置 ffmpeg_path，不应把自动下载当成已成功。中文字体也需在锁定版本里检查文件存在及渲染效果。本轮不把 ImageMagick 列为必装项：当前清单采用 MoviePy 2.x，但最终以实际版本和运行错误为准。[配置示例](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/config.example.toml)

### 6.2 API 对接清单

公共前缀为 /api/v1。[路由基础定义](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/app/controllers/v1/base.py)

| 方法与路径 | 用途 | 对接时核验 |
| --- | --- | --- |
| POST /api/v1/scripts | 通过上游 Provider 生成口播稿 | video_subject、video_language、paragraph_number；返回包装内 video_script |
| POST /api/v1/terms | 提取素材关键词 | 已有接口，P0 本地素材流程不必调用 |
| POST /api/v1/video_materials | 上传素材 | multipart 的 file 字段，核对返回的存储标识和服务端路径 |
| GET /api/v1/video_materials | 查看可用本地素材 | 清单返回字段用于映射生成请求，不能直接传浏览器临时路径 |
| POST /api/v1/videos | 提交异步视频生成 | video_subject、video_script、video_source、video_materials、voice_name、字幕及画幅参数 |
| GET /api/v1/tasks/{task_id} | 查询任务 | 核验响应包装、进度、错误、视频列表 |
| GET /api/v1/stream/{file_path} | 预览产物 | 使用任务返回的位置，不拼接任意用户路径 |
| GET /api/v1/download/{file_path} | 下载产物 | 如启用 API token，携带同一 x-api-key |

脚本及关键词接口可复用，避免 ContentFlow 再构建第二套 LLM 客户端。[LLM 控制器](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/app/controllers/v1/llm.py) 视频提交、上传、状态和文件接口来自视频控制器；API token 与 DeepSeek Key 是两个不同凭证，不能混用。[视频控制器](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/app/controllers/v1/video.py)

视频请求必须显式选择 local、提交已审核 video_script，并传入 video_materials；MaterialInfo 含 provider、url、duration。video_count 固定 1，video_aspect 固定 9:16；不依赖默认 pexels 或默认随机配乐。[参数 schema](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/app/models/schema.py)

本地素材分支执行预处理并跳过在线关键词流程；无有效素材时会失败。不能把“已上传”直接等同于“已选中并可用于任务”。[任务服务](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/app/services/task.py) 状态常量为失败 -1、完成 1、处理中 4，适配后转为 ContentFlow 的可读状态。[常量定义](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/app/models/const.py)

本轮没有编写请求代码或请求样例文件；真实字段以锁定版本 OpenAPI 为准。上传返回值到 video_materials.url 的映射仍需联调，是明确的未验证项。

## 7. 零新增支出的服务组合

| 能力 | 选定方案 | 支出及依赖 | 结论 |
| --- | --- | --- | --- |
| 文案 | 原生 DeepSeek Provider，显式指定 deepseek-flash | 消耗已有账户余额；需要联网和有效 Key | 有依据，未调用验证 |
| 素材 | 自有或允许使用的本地 MP4 | 无素材 API 费用；须提前准备 | P0 必需输入 |
| 配音 | Edge TTS，一种中文音色 | 上游使用无 API Key 的在线服务；依赖网络，无可用性保证 | 最大外部风险之一 |
| 字幕 | subtitle_provider=edge | 利用配音时间戳，本地生成/渲染；依赖 TTS 成功 | 不主动下载 Whisper 模型 |
| 视频合成 | 本地 MoviePy / FFmpeg | 无视频生成 API 费，消耗本机资源 | 需验证编码与字体 |
| 配乐 | 关闭 | 不依赖默认曲库或生成音乐 API | P0 固定关闭 |
| 存储 | SQLite 与本地文件 | 不购买托管数据库或对象存储 | 满足单人 MVP |
| 版本管理 | 本地 Git，后续 GitHub 源码仓库 | 不依赖付费 CI、LFS 或托管 | 媒体及私有配置不纳入仓库 |

DeepSeek 原生 Provider 存在，但当前注册表默认模型为 deepseek-v4-pro，必须显式覆盖为 deepseek-flash，不能只选择 Provider 就认为已使用 Flash。[Provider 注册表](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/app/models/llm_provider.py) 本地配置需设置 llm_provider、deepseek_api_key、deepseek_base_url 和 deepseek_model_name；只在私有配置写入真实值，环境变量是否被上游直接读取必须另查，不能假定 .env 自动生效。[上游配置](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/config.example.toml)

DeepSeek 官方当前列出的 API 模型名为 deepseek-flash，OpenAI 格式地址为 https://api.deepseek.com；这是 DeepSeek 的兼容协议，不需要另购 OpenAI API。[DeepSeek 模型文档](https://api-docs.deepseek.com/quick_start/pricing/)

Edge TTS 仓库明确使用微软在线语音服务并可产出语音和字幕，不能称为本地语音合成。[edge-tts 上游说明](https://github.com/rany2/edge-tts) MoneyPrinterTurbo 配置支持 edge 字幕，未选择 Whisper 时不应自动下载模型；但仍需实测当前版本的中文时间戳和字幕是否成功。[字幕配置](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/config.example.toml)

Azure Speech、ElevenLabs、付费文生视频、云生成配乐、自动发布等均不接入。Pexels/Pixabay 即便有免费额度，也存在注册、Key、限流、归属展示及使用条件，截止前不作为核心依赖。

### 配音失败时的边界

先排查 Edge 的网络、音色和版本兼容，不自动切换付费 TTS。免费备选是用户录音或离线 TTS，但本轮没有把它们写成已经可替换的方案：当前 custom_audio_file 对 API 输入有任务目录限制，而且公开 schema 说明自定义音频通常需 Whisper 对齐字幕；没有已核验的“上传音频 + 外部 SRT 一步注入”接口。因此免费备选会增加音频上传、字幕对齐或适配工作，可能超出剩余时间。[自定义音频限制](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/app/services/task.py)

如果 Edge TTS 验证失败且无法在预算时间内修复，应明确报告阻塞和备选工时；静音视频可证明本地合成，但不能冒充通过有声字幕视频的 P0 验收。

## 8. 模型费用与控制

官方当前美元价：Flash 每百万输入 token（未缓存）高峰 $0.30、低峰 $0.15；输出高峰 $1.20、低峰 $0.60。价格可能变化，实际以账户结算为准。[官方价格](https://api-docs.deepseek.com/quick_start/pricing/)

仅作量级例子：一次 2,000 输入 + 1,000 输出 token，按未缓存高峰价约 $0.0018；20 次同等调用约 $0.036。该示例不含超额推理、额外调用和失败计费，不是余额充足证明；“60 元宝”的人民币兑换及账户适用范围未知，不能直接作换算。

官方当前默认启用思考模式，短文案更适合非思考模式；需检查选定上游 Provider 是否传递关闭思考和输出上限参数。本轮不保证存在可直接写入的配置项，也不为此提前修改上游。[思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)

实施阶段建议：首次仅发极短文本请求；确认实际模型与扣费，再进行少量脚本生成；目标总模型调用 <=20 次，无自动循环生成。检查上游自带重试，不能把“前端只点一次”当作只有一次网络请求。缺乏完整 token 统计时记录“未知”，依据控制台前后余额核对。余额不足时停止，不自动充值或更换付费 Provider。

不启用 DeepSeek Search/Fetch：它们属于另外计费的接口，并非文案生成所必需。

## 9. 最小架构与数据

Streamlit → ContentFlow 薄工作流层 → MoneyPrinterTurbo 本地 REST API → DeepSeek / Edge TTS / 本地 FFmpeg。SQLite 保存任务信息，本地文件目录保存素材、产物和脱敏证据。

优先复用上游异步任务，不再创建 Redis、Celery 或独立复杂执行平台。Streamlit 只保存提交结果并轮询，不能把渲染函数重跑当作重新执行任务。

最小数据对象：任务（主题、当前状态）、执行尝试（确认输入、上游 task_id、时间和错误）、素材引用（文件标识、来源和元数据）、产物（本地位置及上游返回地址）。模型和提示词摘要可随尝试保存；无需先开发完整版本管理界面。

**技术验证门槛 G1：** 先生成约 5–10 秒的固定中文脚本视频，不消耗 LLM；随后极短 DeepSeek 请求验证原生 Provider，再生成 15–30 秒的完整样例。两者都需要真实调用视频 REST API；只跑上游 WebUI 不算 ContentFlow 集成完成。

**交付门槛 G2：** ContentFlow 完成 P0 端到端；至少一个完整样例和一个更换主题的复验；记录总尝试数、失败及实际耗时。不再要求原稿三个主题、全量异常注入或完整历史版本对比。

若 G1 不通过，优先继续处理运行阻塞并压缩 UI，不用模拟视频替代真实验收。若 G2 未通过，报告必须如实写明已完成部分，不能宣称完整 MVP 已交付。
